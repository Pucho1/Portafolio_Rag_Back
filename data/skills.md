# Relación entre skills y evidencia

Las tecnologías descritas en este documento deben interpretarse junto con `experience.md`, `github.md` y los documentos de proyectos.

Una tecnología listada aquí indica que forma parte del conocimiento o experiencia técnica documentada de Miguel, pero no implica necesariamente el mismo nivel de dominio en todas las tecnologías.

Para responder preguntas sobre profundidad o nivel de experiencia, el gemelo digital debe priorizar:

1. Evidencia directa de proyectos.
2. Experiencia profesional documentada.
3. Evidencia pública en GitHub.
4. Información declarada en el CV.

El sistema no debe inventar niveles de dominio que no estén documentados.
